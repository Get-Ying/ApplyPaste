# ApplyPaste Edge Manual E2E Checklist

品牌版 Edge 会屏蔽自动测试使用的命令行扩展加载参数。以下只补充 Edge 外壳与真实 Side Panel 表面检查；业务主路径已由独立浏览器 profile 自动验证。

1. 打开 `edge://extensions`，开启开发人员模式，选择包含 `manifest.json` 的 ApplyPaste 文件夹。预期：无 manifest error，扩展卡片名称为 ApplyPaste。
2. 打开一个测试招聘网页，点击 ApplyPaste，再点击“固定”。预期：Edge Side Panel 打开且刷新网页后仍可重新打开，不影响 Job Paste。
3. 在 Side Panel 创建“测试岗位版”。预期：版本、全部/本版本差异、搜索、分类、快速定位五项同时可见。
4. 新建包含“Python”的项目，搜索 `Python`，编辑并保存字段，再复制字段。预期：搜索词保持，剪贴板只含字段值，出现复制反馈。
5. 滚到正文底部。预期：五项导航仍可操作，底部“稍后继续 / 放弃投递 / 投递完成”固定，最后一项不被遮挡且无横向滚动。
6. 切换到项目经历并滚到第三项，再切到荣誉奖项后返回。预期：项目经历恢复原滚动位置；快速定位目标不被 sticky 遮挡。
7. 点击“投递完成”。预期：当前 URL 自动带入；常见网页尽量带入公司、岗位、地点和 JD，用户可确认修改。
8. 不配置飞书并保存。预期：记录保存到本地，不显示飞书同步失败。
9. 完全退出 Edge 后重开。预期：字段、版本、附件、投递记录和设置仍存在。
10. 同时启用 Job Paste。预期：两者名称、卡片、版本、附件、记录及设置互不读取或覆盖。
