# ApplyPaste 使用指南

> 一次整理，反复填写。用于网申资料管理、快速复制、版本切换和投递记录。

## 30 秒快速开始

**安装 → 导入 Word 简历 → 检查资料 → 打开招聘网页 → 打开 Side Panel → 搜索 / 复制 → 投递完成 → 保存记录**

## 01｜安装与导入简历

### 安装

1. 解压 `ApplyPaste-v0.1-beta.zip`。
2. 在 Edge 打开 `edge://extensions/`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择解压后的 ApplyPaste 文件夹。

### 第一次使用

推荐顺序：**导入 Word 简历 → 检查识别结果 → 补充资料**。

ApplyPaste 会尝试识别基础信息、教育背景、项目经历、实习经历、荣誉奖项和技能等内容。导入后请重点检查：

- 姓名、电话和邮箱是否拆分为独立字段。
- 本科和硕士经历是否混在一起。
- 不同项目是否被错误合并。
- 内容是否进入正确分类。

Word 自动识别可能存在误差，发现问题可直接编辑。

## 02｜网申时怎么用

打开招聘网页后，再打开 ApplyPaste Side Panel。推荐左侧显示招聘网页，右侧显示 ApplyPaste。

### Side Panel 五个核心入口

- **当前版本**：选择本次网申使用的填写版本。
- **全部 / 本版本差异**：查看全部资料，或只看当前版本修改过的内容。
- **搜索**：查找手机号、学校、项目、技能和开放题等内容。
- **分类**：快速进入基础信息、教育背景、项目经历、实习经历、荣誉奖项和附件等分类。
- **快速定位**：直接跳到当前分类中的具体项目或经历。

### 复制与编辑

- **单字段复制**适合手机号、邮箱、学校和专业等短内容。
- **复制全部**适合项目描述、实习描述和开放题等成组内容。
- 资料不准确时，点击“编辑”，保存后继续填写。

![Side Panel 使用方法](images/02-side-panel.png)

## 03｜版本、附件与投递记录

### 填写版本

可为不同岗位创建不同版本，例如通用版、技术岗版、产品岗版或咨询版。岗位版本只需保存与通用版不同的内容；使用“本版本差异”可快速检查改动。

### 附件

可以保存简历、证件照、成绩单、排名证明和其他材料。建议设置一份默认简历。目前支持 PDF 和图片预览，以及 DOCX 近似预览。

### 投递结束后

- **稍后继续**：网申尚未填完。
- **放弃投递**：决定不再投递该岗位。
- **投递完成**：完成投递并保存记录。

ApplyPaste 会尽量自动带入公司名称、岗位名称、工作地点、投递链接、JD、填写版本和使用简历，保存前请人工检查一次。

![版本、附件与投递记录](images/03-version-attachments-records.png)

## 04｜数据保存

ApplyPaste 采用 Local First（本地优先）方式。不开启云服务时，信息库、填写版本、附件和投递记录仍可完整使用。关闭 Edge 后数据正常情况下不会消失。

Beta 阶段建议保留原始简历，并定期在“设置 → 数据管理”中导出完整备份。

## 05｜飞书同步（可选）

不需要飞书同步的用户可以跳过本节。飞书不是 ApplyPaste 的必需功能。

### 同步原理

点击“投递完成”后，ApplyPaste 先保存本地记录。启用飞书后，再同步到飞书多维表格。

ApplyPaste 使用 `ApplyPaste记录ID` 判断岗位记录是否存在：找到已有记录时 UPDATE，未找到时 CREATE。不要删除或清空这个字段，否则可能产生重复记录。

### 创建飞书应用

1. 打开飞书开放平台并创建“企业自建应用”，例如 `ApplyPaste Sync`。
2. 在“凭证与基础信息”中取得 App ID 和 App Secret。
3. 在“开发配置 → 权限管理”中开通多维表格字段读取、记录查询、新增和更新权限。
4. 创建并发布新的应用版本。
5. 打开目标多维表格，通过“添加文档应用”添加该应用并授予编辑权限。

App Secret 相当于密码，不要分享，也不要放进公开截图。

### 创建飞书投递表

最简单可先创建以下六列：

| 飞书字段名 | 推荐类型 | ApplyPaste 映射键 |
| -- | -- | -- |
| 公司名称 | 文本 | `companyName` |
| 岗位名称 | 文本 | `jobName` |
| 工作地点-base | 文本 | `location` |
| 状态 | 单选或文本 | `status` |
| 投递日期 | 日期 | `applyDate` |
| ApplyPaste记录ID | 文本 | `localRecordId` |

`ApplyPaste记录ID` 必须使用普通文本字段，不要设为公式、查找引用或自动编号。

公共版还支持以下五个可选映射：

| 飞书字段名（默认） | 推荐类型 | ApplyPaste 映射键 |
| -- | -- | -- |
| JD | 多行文本 | `jd` |
| 投递链接 | 超链接或文本 | `jobUrl` |
| 备注 | 多行文本 | `notes` |
| 使用简历 | 文本 | `resumeName` |
| 填写版本 | 文本 | `profileVersion` |

内推人、内推码、行业、岗位类别、优先级、渠道、企业性质、招聘批次和有效性修正仍可保存在本地，但公共版不会默认同步这些字段。

### 取得表格链接

常见链接格式：

```text
https://example.feishu.cn/base/bascnxxxxxxxxxxxx?table=tblxxxxxxxxxxxx
```

- `/base/` 后的 `bascn...` 是 `app_token`。
- `?table=` 后的 `tbl...` 是 `table_id`。

一般直接复制完整链接即可。

### 在 ApplyPaste 中配置

1. 打开“设置 → 飞书同步”。
2. 启用飞书同步。
3. 填写 App ID 和 App Secret。
4. 粘贴飞书多维表格链接。
5. 链接未自动解析时，手动填写 `app_token` 和 `table_id`。
6. 展开“字段映射”。

映射左侧是 ApplyPaste 内部字段，右侧填写自己的飞书真实列名。例如飞书列叫“工作地点”，则填写：

```text
location → 工作地点
```

不要填写 `tbl...` 或 `fld...` 编号。列名必须与飞书中的名称逐字一致。

![飞书表格与字段映射](images/04-feishu-setup-and-mapping.png)

### 测试连接与首次同步

1. 点击“测试连接”。
2. 确认出现“连接成功，读取 N 个真实字段”。
3. 检查能否看到自己创建的飞书列，再保存设置。
4. 使用一个测试岗位执行“投递完成 → 保存并同步”。
5. 确认飞书出现新记录，且 `ApplyPaste记录ID` 非空。
6. 对同一记录执行“同步更新”，确认更新原行而非新增第二行。

测试连接本身不会新增投递记录。

![飞书同步验收与排错](images/05-feishu-sync-troubleshooting.png)

### 常见问题

- **App ID / App Secret 缺失**：重新从飞书开放平台复制凭证。
- **app_token / table_id 缺失**：复制具体数据表的完整链接，或手动填写。
- **HTTP 403 / Permission denied**：检查 API 权限、应用版本发布状态、文档应用授权和编辑权限。
- **必填字段不存在**：检查飞书列名和字段映射是否逐字一致。
- **日期写入失败**：将“投递日期”设为飞书日期字段。
- **状态写入失败**：先使用文本字段，或在单选字段中建立对应选项。
- **同步成功但部分字段为空**：检查投递记录是否填写、映射是否正确，以及目标列是否存在。

清除飞书配置只会删除当前浏览器中保存的凭证，不会删除飞书表格中的记录。

## 第一次使用路线

**安装 → 导入 Word 简历 → 检查资料 → 打开招聘网页 → 打开 Side Panel → 搜索 / 复制 → 投递完成 → 保存记录**

飞书同步需要时再配置，不需要可以完全不启用。
