# Known Issues

ApplyPaste v0.1 Beta 已覆盖资料整理、网申复制、版本管理和投递记录这条核心流程。以下限制用于记录实际使用中仍需人工确认的地方，不影响本地优先的核心工作流。

## 当前限制

- 特殊 Word 排版可能影响简历识别结果，导入后建议人工检查分类、条目和字段。
- 不同招聘网站的页面结构差异较大，公司、岗位、地点、JD 和链接可能需要保存前手动确认。
- DOCX 预览为近似预览，可能无法完全还原 Word 原始排版。
- 对重要网申资料，建议保留原始 Word / PDF 文件，并定期导出完整备份。

## 反馈建议

反馈问题时，建议提供操作步骤、实际结果、预期结果和截图。涉及简历或个人资料时，请先遮挡姓名、手机号、邮箱、身份证号等敏感信息。
